## 目的（何ができれば完了か）

「失敗しているのに誰も気づけない」形の不具合を 3 つまとめて塞ぐ。**壊れているのと正常なのが出力から区別できない**状態を無くす。

## 受け入れ条件（検査で確認できる形に）

[spec](../../spec/no-silent-failures.md) の A / B / C。**3 つとも「回帰を止める検査」を条件に含めている**（この題材の性質上、検査が無ければ同じことが再発する）。
